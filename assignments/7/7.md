The goal of this assignment is to devise the best possible model for the Tagger task (assign a part of speech to each word or punctuation mark in the input sentence) on the czech_cac.zip dataset. You can load the data using the morpho_dataset.py module. You may want to start with the 11-tagger_we task.

Everyone who submits a solution before the due date and that achieves at least 95.00% accuracy on the dev set will receive 20 points. Three models with the best accuracies (on the dev set) will receive bonus points depending on the relative ordering of the solutions (15 points for the 1st place, 10 points for the 2nd place, 5 points for the 3rd place). Everyone who submits a solution achieving at least 95.00% accuracy (on the dev set) after the due date but before the cutoff date (June 3, 2026, 08:00 a.m.) will receive 15 points. For this task, you may work in teams of at most two members. In that case, EACH member must submit the same files and declare all team members (you can use the comment section of the Moodle submission system). All the team members will then receive the same points according to their solution.

For submission, submit your training script with all specified parameters, the final trained model (or at least model weights; if the file is too large, please use a file-sharing service such as filesender.cesnet.cz or uschovna.cz), and the accuracy on the dev set (write it in the comments of the Moodle assignment submission). Check your code using the provided 07_code_check.py and also submit the modified 07_code_check.py file.

If the model file (or model weights file) is too large for submission (above 100 MB limit), please use filesender.cesnet.cz, uschovna.cz, etc., and include the download link in the comments. Please do not publicly share your solutions or models (e.g., on GitHub). If you use GitHub, set the repository to private and share it only with me (username: computer-binary-code) instead of making it public.

Do not use or load any model with weights pretrained on other datasets. Reimplementing the architecture of existing models or using built-in model definitions (without pretrained weights) is allowed (if you have doubts, contact me). The only exception for this is that you can use or load any other pretrained word-level or character-level embeddings or load any other pretrained model used essentially only for creating word- or character-level embeddings.
